# Выполнение SEO / GEO

Дата: 5 сентября 2026. Цели: найм и консалтинг с равным приоритетом.

## Реализовано

- Переработан план на 90 дней; исходник сохранён в `seo/archive/`.
- 12 canonical URL в общем реестре. Из него строятся Vite inputs, sitemap, AI-выгрузки и список допустимых страниц аналитики.
- Автоматические проверки canonical, hreflang, FAQ, дат, внутренних ссылок и robots в сборке и CI. 12 регрессионных SEO-тестов.
- Исправлены наследование robots для AI-ботов, размеры OG, мобильное переполнение.
- Переработан обзор 15 авторов в RU/EN: ссылки на первоисточники, выбор по задаче, убраны спорные биографии, цитата, превосходные оценки и неподтверждённые рассказы о результатах.
- Новая статья `data-and-interviews.html` в RU/EN: выбор метода Discovery, проверка данных, арифметическое разложение конверсии, ограничения причинного вывода, шаблон решения, два контактных сценария. Пример явно учебный.
- Неопределённые `$100M+`, ARR/P&L и точные обещания интервью убраны до подтверждения. В SheSafe schema удалены непроверенные стоимость, минимальная версия iOS и обещание шифрования; само приложение не проходило технический аудит.
- GSC и Яндекс API подключены, реальный baseline и инспекция URL получены. Credentials и Google JSON сохранены локально с ограниченными правами; не попадают в Git/Docker/Vite. Закрытые данные — `seo/private/`.
- Аналитика переведена на существующий Cloudflare Worker. Отдельные `click-gcal-hiring` / `click-gcal-consulting`, поддержка всех HTML-событий, укрупнённые источники и сохранение атрибуции между страницами.
- Исправлена потеря параллельных событий: отдельная KV-запись на каждое принятие вместо неатомарного счётчика. Срок хранения новых записей 180 дней. Проверены конкурентные события, неподдерживаемые URL и контракт HTML. 10 JS и 3 Python-теста.
- Проведён мобильный Lighthouse; по его данным убраны тяжёлые декоративные логотипы из первого экрана, внешний блокирующий CSS шрифта и анимация появления основного текста. Шрифт размещён локально с лицензией.
- Запущен воспроизводимый Gemini API pilot на фиксированных вопросах; сырые ответы и источники закрыты. Это не измерение ChatGPT/Perplexity.

## Выпуск и проверки

Код подготовлен к публикации через действующий GitHub Pages workflow. Финальный статус выпуска, HTTP-проверки и sitemap будет добавлен после их выполнения. Worker уже обновлён отдельно.

`npm run build`, `npm run test:seo`, `npm test` выполняются перед отправкой. Исходный HTTP-снимок `seo/live-baseline.json` относится к старой версии; его замечания не следует переносить на новую без повторной проверки.

## Осталось / ограничения

1. Подтверждённый личный кейс: точная метрика, период, метод атрибуции, вклад и разрешённые доказательства. Даты опыта и реальные гарантии SheSafe требуют владельца.
2. GA4 Admin API вернул `SERVICE_DISABLED`. Нужны включение Analytics Admin/Data API и доступ к GA4 property; GSC доступ его не заменяет.
3. Полевой CrUX не получен. PageSpeed API вернул 429; лабораторный Lighthouse не даёт оценки полевого INP/CWV.
4. Повторить индексацию и запросы через 2–4 недели; HTTP 200 и принятие sitemap не гарантируют включение в поиск.
5. Разделять клик контакта и состоявшийся квалифицированный разговор. Последний требует обратной связи владельца по найму/консалтингу.
6. Продолжение контентного кластера и внешние публикации — после доказательств и сигнала спроса. Сообщения редакциям и третьим лицам не отправлялись.
7. Межплатформенный AI-бенчмарк и повтор через четыре недели; API pilot одного сервиса не даёт универсальный GEO Score.
